# eleday

Интерактивные статьи в дополнение к видео и постам в Telegram. Максимально простой статический сайт: HTML, CSS и JavaScript, без сборки и обязательных зависимостей.

## Структура

```text
site/                       Только публичные файлы; корень сайта
  index.html                Каталог статей, обновляется вручную
  assets/css/main.css       Общая типографика, темы и компоненты
  assets/js/theme.js        Переключение и сохранение темы
  assets/images/            Общие изображения
  articles/demo/            Тестовая статья и её интерактив
    index.html
    article.js
templates/article.html      Основа новой статьи, не публикуется
docs/adding-articles.md      Порядок добавления материалов
AGENTS.md                   Правила для агентов
server.py                   Локальный сервер на Python
.github/workflows/pages.yml Публикация site/ в GitHub Pages
```

## Посмотреть локально

Из корня репозитория:

```sh
python3 server.py
```

Откройте http://127.0.0.1:8000, затем тестовую статью. Остановить сервер: Ctrl+C. Другой порт: `python3 server.py --port 8080`. Сервер доступен только на этом компьютере и раздаёт папку `site/`; путь определяется относительно скрипта, поэтому запускать его можно из любой директории. После правок обновите страницу в браузере. Установка пакетов не нужна. Manrope загружается из Google Fonts; без сети используется системный шрифт. При необходимости можно позже разместить WOFF2 локально вместе с лицензией.

## GitHub Pages

1. Отправьте коммит в `main`: `git push origin main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. При необходимости запустите **Actions → Deploy GitHub Pages → Run workflow**. Дальнейшие push в `main` публикуются автоматически.

Ожидаемый адрес для текущего origin: https://eledays.github.io/eleday/. Фактический адрес будет в результате workflow. Публикуется только `site/`, инструкции и шаблоны остаются в репозитории. Все внутренние пути относительные, поэтому сайт работает и под `/eleday/`, и на собственном домене.

Workflow следует [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages). Настройки GitHub и отправка коммитов выполняются отдельно; наличие workflow само по себе не включает Pages.

## Оформление и статьи

Светлая тема — желтовато-белый фон; тёмная — серо-чёрный. Manrope, узкая колонка текста, адаптивные изображения и спокойные интерактивные блоки. Код всегда на тёмном фоне. Тема выбирается по настройке системы, ручной выбор сохраняется в браузере.

Начните с [инструкции по добавлению статей](docs/adding-articles.md). Демо: `site/articles/demo/index.html`. Реальные ссылки на канал и видео добавляются после получения адресов.
